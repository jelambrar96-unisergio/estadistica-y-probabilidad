# Estadística y Probabilidad

Este repositorio contiene los materiales, ejercicios y recursos para el curso de **Estadística y Probabilidad** de la Universidad Sergio Arboleda.

## Estructura del Proyecto

A continuación se detalla la organización de los archivos y carpetas en este repositorio:

- `clases/`: Contiene subcarpetas para cada sesión del curso. Cada carpeta de clase suele incluir:
  - `README.md`: Explicación detallada de los temas tratados.
  - `codes/`: Ejemplos de código y scripts.
  - `ejercicios/`: Guías y problemas propuestos.
  - `media/`: Imágenes y recursos visuales complementarios.
- `cohorts/`: Agrupa los materiales específicos para diferentes periodos académicos (ej. `2026-a`, `2026-b`).
- `.vscode/`: Configuraciones del entorno de desarrollo sugeridas para el curso.
- `.gitignore`: Archivos y carpetas excluidos del control de versiones.

## Contenido de las Clases

El curso está organizado de forma secuencial:

- [**Clase 00**](clases/clase-00-introduccion-curso/README.md): Introducción al curso.
- [**Clase 01**](clases/clase-01-introduccion-estadistica-descriptiva/README.md): Introducción a la estadística descriptiva.
- [**Clase 02**](clases/clase-02-medidas-tendencia-central-dispersión/README.md): Medidas de tendencia central y dispersión.
- [**Clase 03**](clases/clase-03-introduccion-probabilidad/README.md): Introducción a la probabilidad.
- ...y así sucesivamente hasta cubrir todo el currículo.

## Requisitos y Configuración

Para trabajar con estos materiales, se recomienda tener instalado:

- Un editor de texto (preferiblemente Visual Studio Code).
- Entornos de ejecución según el lenguaje utilizado en `codes/` (ej. Python, R, etc.).

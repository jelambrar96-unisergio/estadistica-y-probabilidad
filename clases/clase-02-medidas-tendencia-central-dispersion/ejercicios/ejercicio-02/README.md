# Ejercicio 02

**1.4** En un estudio realizado por el Departamento de Ingeniería Mecánica del Tecnológico de Virginia se compararon las varillas de acero que abastecen dos compañías diferentes. Se fabricaron diez resortes de muestra con las varillas de metal proporcionadas por cada una de las compañías y se registraron sus medidas de flexibilidad. Los datos son los siguientes:

- **Compañía A**: `9.3, 8.8, 6.8, 8.7, 8.5, 6.7, 8.0, 6.5, 9.2, 7.0`
- **Compañía B**: `11.0, 9.8, 9.9, 10.2, 10.1, 9.7, 11.0, 11.1, 10.2, 9.6`

1. Calcule la media y la mediana de la muestra para los datos de ambas compañías.
2. Grafique los datos para las dos compañías en la misma línea y explique su conclusión respecto de cualquier aparente diferencia entre las dos compañías.
3. calcule tanto la media como la varianza de la “flexibilidad”para las compañías A y B. ¿Parece que hay una diferenciade flexibilidad entre la compañía A y la compañía B? (Ejercicio 1.10)

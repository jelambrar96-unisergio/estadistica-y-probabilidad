# Ejercicio 03

2.15 Considere el espacio muestral

$S = \{$ cobre, sodio, nitrógeno, potasio, uranio, oxígeno, cinc $\}$

y los eventos

$A = \{$ cobre, sodio, cinc $\}$

$B = \{$ sodio, nitrógeno, potasio $\}$

$C = \{$ oxígeno $\}$

Liste los elementos de los conjuntos que corresponden
a los siguientes eventos:

1. $A'$;
2. $A \cup C$;
3. $(A \cap B') \cup C'$;
4. $B' \cap C'$;
5. $A \cap B \cap C$;
6. $(A' \cup B') \cap (A' \cap C)$.

Tomado de Walpole, R. E., Myers, R. H., Myers, S. L., & Ye, K. (2012). *Probabilidad y estadística para ingeniería y ciencias* (8a ed.). Pearson Educación.
